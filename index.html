Press Room is a work of fiction. All clubs, players, journalists, outlets, referees and sponsors are invented. Keys: 1-6 tones, T type, Enter send, N next.

Live journalists (optional)

The game is fully playable offline. If you paste your own Anthropic API key, journalists will write follow-up questions that react to the words you type, and the back-page headline is written live by a fast, low-cost Claude model.

  • Your key is stored only in this browser's localStorage.
  • It is sent only to api.anthropic.com, directly from your browser. There is no server in between.
  • Calls are billed to your account. Each typed answer is one short request; each back page is one more.
  • Anyone with access to this browser profile could read a stored key. Use "Forget key" when you are done.
